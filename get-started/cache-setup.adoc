= Configurar el almacenamiento en caché de volumen
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para utilizar el almacenamiento en caché de volumen, realice algunos pasos para configurarlo.

* Revisarlink:../get-started/cache-prerequisites.html["prerrequisitos"] para garantizar que su entorno esté preparado.
* Crear un agente de consola.
* Cree sistemas que puedan admitir el almacenamiento en caché de volumen.




== Crear un agente de consola en la consola de NetApp

El siguiente paso es crear un agente de consola en la consola de NetApp .

Para crear un agente de consola antes de usar el almacenamiento en caché de volumen, consulte la documentación de la consola de NetApp que describe https://docs.netapp.com/us-en/bluexp-setup-admin/concept-connectors.html#how-to-create-a-connector["Cómo crear un agente de consola"^] .



== Crear sistemas

Si aún no lo ha hecho, debe crear los sistemas para el origen y el destino.

* https://docs.netapp.com/us-en/cloud-manager-fsx-ontap/start/task-getting-started-fsx.html["Cree un sistema Amazon FSx para ONTAP"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-otc-aws.html["Lanzamiento de Cloud Volumes ONTAP en AWS"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-otc-azure.html["Lanzamiento de Cloud Volumes ONTAP en Azure"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-gcp.html["Lanzamiento de Cloud Volumes ONTAP en GCP"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-adding-systems.html["Agregar sistemas Cloud Volumes ONTAP existentes"^]
* https://docs.netapp.com/us-en/cloud-manager-ontap-onprem/task-discovering-ontap.html["Descubra los clústeres de ONTAP"^]
